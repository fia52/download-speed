# Измерение скорости скачивания

Консольный скрипт для Python 3.9+ без сторонних зависимостей.

## Запуск в WSL

```bash
cd ~/workspace/test-projects/download-speed
python3 download_speed.py 'https://example.com/image.jpg'
```

Замените пример на HTTP/HTTPS-адрес нужного файла.

Скрипт делает 10 последовательных запросов. Каждый ответ полностью
считывается до начала следующего запроса. Данные читаются блоками по 64 KiB
и не сохраняются на диск. HTTP-перенаправления обрабатываются автоматически.

В консоли выводятся количество запросов, среднее время одного запроса,
общий объём скачанных тел ответов в байтах и MiB, а также скорость в **MiB/с**.
Один MiB равен 1 048 576 байтам.

Скорость считается как общий объём данных, делённый на сумму времени всех
запросов. Среднее время — сумма времени запросов, делённая на 10.
Замер включает установление соединения, ожидание сервера и чтение полного
ответа; размер HTTP-заголовков и сетевые накладные расходы в объём не входят.
Это средняя скорость скачивания с выбранного адреса, а не предельная
пропускная способность интернет-соединения.

Тайм-аут блокирующих сетевых операций — 60 секунд (не общий лимит времени
скачивания). При сетевой ошибке, HTTP-ошибке или неполном ответе с указанным
Content-Length скрипт выводит причину и завершается с кодом 1 без итоговой
статистики. Неверные аргументы дают код 2.
